# st-2026-2-trabajo1-STS9J7
En este proyecto analizamos 3 series aplicando distintos métodos de pronóstico desarrollados a mano en R. A lo largo del trabajo, respondemos preguntas clave para entender el comportamiento de cada serie, aprendemos a identificar sus patrones y validamos los errores mediante un esquema de origen móvil para generar las proyecciones finales.
